# Crypto MA-Crossover Trading Bot (Binance)

Trades BTC/USDT using a short-MA/long-MA crossover signal.

## Setup

1. **Create a Binance API key**
   https://www.binance.com/en/my/settings/api-management
   - Enable **Spot & Margin Trading**
   - Do **NOT** enable withdrawals on this key
   - Restrict the key to your IP if possible

2. **Set your API credentials as environment variables** (never hardcode them in the script)
